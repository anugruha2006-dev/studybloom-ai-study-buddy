STUDYBLOOM — STANDALONE AI STUDY BUDDY
======================================

This is a separate, self-contained project. It does not modify your existing ai_study_helper folder.

RUN IT (NO INSTALLATION REQUIRED)
1. Extract AI_Study_Buddy_Standalone.zip into a new folder, for example Desktop\StudyBloom.
2. Open the extracted folder.
3. Double-click index.html. It opens in your default browser.
4. Paste notes and try Make summary, Create flashcards, and Make quiz.

IMPORTANT
- No npm, package.json, Python packages, server, or API key is needed.
- This is a local rule-based study helper, not a cloud AI model. It creates simple summaries, flashcards, and quizzes from your notes.
- “Save notes on this device” stores notes in the browser's local storage for that browser.
- Your existing project files are not changed.
